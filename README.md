# Eventos

A simple, responsive landing page for an events discovery website. The homepage is a standalone static site in `index.html`—no build tools or dependencies required.

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. In the repository, open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and the `/ (root)` folder, then click **Save**.
4. After the first deployment, the site should be available at <https://danialgiacamanhub.github.io/Eventos/>.

The event cards are sample content. Replace them with real event names, dates, locations, and links before promoting the site.
